# express-101

This is a study project where I collect practical examples from the Express courses by Alura and Mimo as I learn how to build web servers and APIs with Node.js.

It is not an application with a single purpose. It is a living repository that can grow with new exercises, routes, middleware, and API examples over time.

## Stack

- Node.js
- JavaScript with ES Modules
- Express, as covered throughout the courses

## Purpose

Serves as a personal study reference, with no fixed roadmap. New topics and refactors will be added as the courses progress.
